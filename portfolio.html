01 About

The systems behind the work

I started where most business-development careers start — calls, outreach, lead lists. What I kept noticing was how much of the work wasn't the work. Proposals reassembled from scratch each time. Prospects contacted before anyone had looked at their business. Data copied between spreadsheets by hand.

So I started fixing the layer underneath. At Verve Advisory I built a Claude-based proposal system — a dedicated knowledge base for each freelancer — and proposals went from hours to about fifteen minutes. When the company set a monthly learning challenge, I had never written a line of code. I taught myself Claude Code, Supabase and GitHub, and turned our Google Sheets bid log into a working web app anyway.

Built with no formal development background.

That line sits in my CV as a footnote. I'd rather it be the headline. It's the thing I'd want a team to know about me: when something is broken and slow, I don't file it as a complaint — I go and build the thing that fixes it.

Today I own the Upwork business-development engine for up to 6+ freelancer profiles — screening jobs, running up to 15 targeted bids a day, and positioning each profile for the clients it wants to win. Before that, at Wildnet Technologies, I drove pipeline generation with research-led prospecting: an SEO audit and Semrush analysis on every prospect before first contact.

07 How I work

Four things I keep coming back to

01

Fix the system, not the symptom

A proposal rewritten from scratch every time isn't a writing problem. It's a system problem. I go one layer down.

02

If it happens weekly, automate it

Anything repeated is a candidate. Hours became fifteen minutes because the task was the same every time.

03

Clean data, or no data

A CRM the team doesn't trust is worse than no CRM. Hygiene isn't admin — it's what makes the numbers usable.

04

Learn it, then build it

I had no development background. The company set a learning challenge, so I learned Claude Code, Supabase and GitHub and built the thing.
