01 About

The systems behind the work

I started where most marketing careers start — campaigns, outreach, client calls. What I kept noticing was how much of the work wasn't the work. Reports rebuilt by hand every Monday. Proposals reassembled from scratch each time. Pipeline data nobody quite believed.

So I started learning how to fix the layer underneath. My manager set me a project to build an internal reporting tool, and I had never written a line of production code. I taught myself Supabase, GitHub and VS Code, and built one anyway — lead capture, CRM data and dashboard analytics in a single working system.

Built with no formal development background.

That line sits in my CV as a footnote. I'd rather it be the headline. It's the thing I'd want a team to know about me: when something is broken and slow, I don't file it as a complaint — I go and build the thing that fixes it.

Today I run marketing operations for 6+ client accounts — CRM and pipeline hygiene, cold email sequencing, LinkedIn outreach, campaign tracking and the positioning assets that turn a view into a conversation. Before that I owned the full client journey at Wildnet Technologies, from first touch to live campaign.

07 How I work

Four things I keep coming back to

01

Fix the system, not the symptom

A report that's wrong every week isn't a reporting problem. It's a plumbing problem. I go one layer down.

02

If it happens weekly, automate it

Anything repeated is a candidate. Four hours became fifteen minutes because the task was the same every time.

03

Clean data, or no data

A CRM the team doesn't trust is worse than no CRM. Hygiene isn't admin — it's what makes the numbers usable.

04

Learn it, then build it

I had no development background. I was handed a brief anyway, so I learned Supabase and GitHub and built the thing.
